  🚀 THREE WAYS TO BUILD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1️⃣  EASIEST (Recommended)
      Press: Ctrl+Shift+B
      Does:  Full clean build + compile
      Use:   Major changes, new citations, troubleshooting
      
  2️⃣  FAST
      Press: Ctrl+B
      Does:  Quick compile (no cleaning)
      Use:   Minor text edits, small fixes
      
  3️⃣  CLEAN ONLY
      Press: Ctrl+Shift+C
      Does:  Remove all build artifacts
      Use:   When you need a fresh start

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  📝 TYPICAL WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Open main.tex in VS Code
  2. Make edits
  3. Press Ctrl+Shift+B
  4. Wait for ✅ "All targets up-to-date" message
  5. View main.pdf
  6. Repeat or commit

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ❌ IF BUILD HANGS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  This should NOT happen anymore!
  
  If it does:
  1. Check main.log for actual errors (not warnings)
  2. Press Ctrl+C to cancel
  3. Fix the error
  4. Press Ctrl+Shift+B again
  
  The .latexmkrc file prevents infinite loops by limiting
  builds to 8 passes maximum.
